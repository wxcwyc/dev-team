# observability-logging

可观测性/日志技能：让问题“可定位”，而不是“玄学”。

## 适用场景
- 新服务/新模块
- 线上问题频发、难复现
- 需要基本 SLO/性能指标

## 输出（必须包含）
- 日志字段规范：时间/级别/模块/request id/user id(如有)/错误栈
- 关键路径埋点：请求入口、外部依赖调用、DB 操作耗时
- 错误分级：可重试/不可重试
- 最小监控建议：健康检查、错误率、延迟（p95）

## 最小标准
- [ ] 每个请求都有 request id（前端传入或后端生成）
- [ ] 错误日志包含 stack + 业务上下文
- [ ] /health 可用
